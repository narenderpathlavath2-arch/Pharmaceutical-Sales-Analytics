Pharmaceutical Sales Analytics Dashboard

 Project Overview

This project is an interactive Pharmaceutical Sales Analytics Dashboard developed using Microsoft Power BI.

The dashboard analyzes pharmaceutical sales data and presents the information through interactive visualizations and key performance indicators.

 Objectives

- Analyze pharmaceutical sales performance
- Understand sales trends and patterns
- Monitor key sales metrics
- Analyze product and business performance
- Present insights through an interactive Power BI dashboard

 Tools Used

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

 Dataset

The project uses a pharmaceutical sales dataset provided in CSV format.

The dataset is used as the source for data preparation, analysis, calculations, and dashboard visualization in Power BI.

 Dashboard

The Power BI dashboard provides interactive analysis of the pharmaceutical sales data using charts, tables, filters, and KPI cards.
